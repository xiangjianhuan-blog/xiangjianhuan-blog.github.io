复现提示词：黄昏海岛 1.0

这是《vibe coding：黄昏海岛 1.0》那篇文章的配套提示词。

那篇文章记录的是「过程」，这一页给的是「入口」——把整轮对话里真正起作用的那些决定抽出来，压成一份可以直接粘进 AI 编码助手的任务书。它不保证一字不差地复刻，但能保证同样的结构、同样的坑、同样的验收方式。

适用对象：能读写本地文件、能执行命令的 AI 编码助手（WorkBuddy、Claude Code、Cursor 之类）。全程一个人、一次会话、零构建。

预期产出： 单个 index.html（约 6800 行）+ assets/models/（75 个 CC0 GLB，约 26 MB）+ start.bat。

一、主提示词（整段复制）

下面这一整块就是提示词本体。一次性给全，不要拆开分轮喂——它内部有顺序依赖，拆开会让 AI 在前面缺少约束的情况下做出后面要推翻的决定。

二、为什么是这么写的

这份提示词里几乎没有「做得好看一点」这种话。每一条约束背后都对应一次真实的返工，把它们反推回去，大致是这样：

提示词里的段落 它真正在防什么 对应那次踩的坑
0. 交付形态 防止 AI 自作主张拆模块、上构建工具 单文件是这个项目的核心约束，一旦破掉，后面每条都要重写
1. 环境红线 防止「静默失败」被当成「没生成」 双击打不开，file:// 下 GLB 全部消失，控制台才有 CORS
2. waveAt 与着色器共用参数 防止船和水面各算各的 船浮在水下或悬在水上，都是两套波参数造成的
3. 高度带 + 密度倍数 把审美判断翻译成可执行参数 「树怎么长在沙滩上」——原实现只看噪声不看高度
4. 射线量甲板 防止假设甲板是平的 换模型后玩家站在半空或陷进甲板
5. 海床与岸坡同式 防止两套地形函数打架 岸线与海床重叠区穿模、出现台阶
6. 分带 + InstancedMesh 防止「撒点式」生态和性能崩塌 鱼群逐帧改顶点 → 掉帧；生物全在同一深度
7. 四件套 + 滞回 让「水下质感」可验收 「要有潜水的感觉」无法执行，拆成雾/焦散/光束/折射才行
8. 9 帧表 + 夜里负仰角 防止硬编码时段、防止夜里太阳不落山 夜晚海水发青绿，根因是太阳仍在地平线上
9. 11 个乘子 让「天气过渡」有唯一实现路径 逐种天气写 if 分支 → 切换必然硬切
10. OutputPass 防止中途创建渲染目标 下潜瞬间卡顿一秒，全材质重编译
11. 禁止清单 防止用基本几何体凑数 用户明确要求：海鸥、云也不能自己搭
12. 十条验收 把「完成」定义清楚 不写验收，AI 会以「代码跑通」为完成

一个反直觉的地方：提示词里最值钱的不是「要什么」，而是「不许什么」。约束越具体，AI 的自由度越落在正确的地方。第 11 条那五句禁止，比前面十节加起来省的时间都多。

三、验收清单（可以直接照做）

把这张表当成 checklist。前六条不过关，先别加新功能——后面所有效果都建立在这六条之上。

  • file:// 打开 → 引导卡出现，不是白屏
  • start.bat 打开 → 控制台 0 报错，GLB 就位 69/69
  • 沙滩看山：山顶密林、沙滩只有棕榈、水线无树
  • 上船转舵：船贴水面起伏，人在甲板不穿模
  • 下潜：雾 + 焦散 + 光束 + 鱼群 + 仰视天窗，五样齐
  • 四个时刻各截一张：黎明 / 正午 / 黄昏 / 夜晚，色调都对
  • 暴风雨：乌云 + 斜雨 + 白浪 + 闪电 + 水下能见度骤降
  • 海雾：远岛消失但不发白
  • 按住左键演奏、松开换曲
  • pageerror 与 4xx 请求均为 0

四、如果你是在改造已有项目

上面那份是从零起。如果手上已经有一个能跑的版本，只是要加海底、昼夜和天气，用这份增量版更省事——关键是先说清楚什么不许动：

五、这条提示词本身是怎么来的

不是一开始就写成这样的。真实顺序是反过来的：先撞墙，再把墙记下来。

第一版需求只有一句话——「加入海底地形和生态，游泳要有潜水的质感」。这句话对一个 AI 来说几乎无法执行：什么叫质感？加几层雾算够？所以第一轮出来的东西一定是「看起来有，但不对」。之后每一轮对话，实际上都在做同一件事：

把一句「我觉得不对」翻译成一句既能让 AI 执行、又能让我验收的话。

「树不该长在沙滩上」→「按高度带分配物种，山顶密度 3 倍于山腰」。
「水下没感觉」→「雾/焦散/体积光/折射四件套 + 仰视斯涅尔窗」。
「天气切换太突然」→「11 个乘子，当前值向目标值 lerp，时间常数 2–4 秒」。

每完成一次翻译，就往这份提示词里加一条。所以上面那 13 节，本质是 13 次返工的沉淀物。

如果你要拿它做别的东西，真正该抄的不是那些数字，是这套结构：先锁交付形态，再定红线，然后每个效果给出可验收的分解，最后写禁止清单和十张截图。
