## 二、复刻提示词（复制即用）

> 用下面整段作为一次性需求，交给能写代码的 AI。

你是一名擅长 Canvas 的前端工程师。请用**单个 HTML 文件**实现一个「网页画图工具 Pro」，CSS 与 JS 全部内嵌，双击即可在浏览器打开使用。除可选的 CDN 笔迹库外，不依赖任何外部资源、框架或后端。

### 1. 技术约束
- 单文件 `drawing-tool.html`，中文界面，`lang="zh-CN"`。
- 画布文档固定 1600×1000 逻辑像素；所有图层 canvas 按 `devicePixelRatio`（上限 2）放大并 `setTransform(DPR,0,0,DPR,0,0)`，保证高清。
- 唯一可选外部依赖：`https://esm.sh/perfect-freehand@1.2.0`，用 `<script type="module">` + `try/catch` 动态 import，失败必须自动降级到内置印章引擎，不能白屏或报错。
- 代码组织：IIFE + `'use strict'`，按功能分区注释（配置 / 主题 / 光标 / 图层 / 缩放 / 印章 / 笔迹 / 图形 / 选区 / 文字 / 钢笔 / 油漆桶 / 历史 / 事件绑定）。

### 2. 页面布局
- 顶部工具栏（吸顶，`position: relative; z-index: 20`）：
  - 左：7 个工具按钮（画笔 B、橡皮擦 E、图形 R、文字 T、钢笔 P、油漆桶 F、选择 M），带内联 SVG 图标，选中态蓝底白字。
  - 图形类型下拉（矩形 / 圆角矩形 / 椭圆 / 三角形 / 菱形 / 五角星 / 直线 / 箭头）+「填充」复选框。
  - 颜色区：11 个预设色板 + `<input type="color">` 自定义取色 + 一个小圆点实时预览当前颜色与透明度。
  - 大小滑块 1–80（默认 8）+ 数值徽章；透明度滑块 0–100（默认 100）；线型下拉（实线/虚线/点线）；笔刷下拉（圆形/方形/书写笔/毛笔/油画笔/蜡笔/水彩画笔）。
  - 右：撤销、重做、清空（危险色）、导出格式 PNG/JPG、保存（主按钮）、主题切换图标按钮。
  - 工具栏下方是三条**浮层**设置条（`position: absolute`，不占布局高度，切到对应工具才显示）：文字设置条、钢笔提示条、选区工具条。
- 中间：带棋盘格底纹的舞台，居中放置白纸 `.paper`；右下角缩放条（− / 百分比 / + / 适应）；左下角操作提示。
- 右侧：图层面板（标题 + 「+ 新建」、图层列表、底部 ↑ ↓ 删除）。
- 底部：一行快捷键说明条。

### 3. 画笔
- 采用**印章引擎**：为每种笔刷用 128×128 离屏 canvas 生成笔尖蒙版（`buildMask`），再用 `source-in` 着色成当前颜色的笔尖（按 类型+颜色 缓存）。绘制时沿鼠标轨迹按固定间距 `drawImage` 盖章，用 `carry`（里程余量）保证跨帧连续、不断续。
- 笔刷参数（间距 = 笔宽 × 系数，alpha = 单次印章不透明度）：
  - 圆形：0.10 / 1.00，径向渐变软边
  - 方形：0.14 / 1.00，实心方 + 轻微边缘
  - 书写笔：0.05 / 0.95，硬边圆，走 perfect-freehand（thinning 0.62）
  - 毛笔：0.05 / 0.95，竖向压扁椭圆 + 笔毫细纹；perfect-freehand thinning 0.82；笔宽随运笔速度变化（越快越细，1.2 → 0.55 倍）
  - 油画笔：0.08 / 0.85，方形鬃毛块 + 竖向缝隙 + 两端毛糙；印章随轨迹方向旋转
  - 蜡笔：0.14 / 0.90，圆头 + 260 个随机镂空颗粒
  - 水彩画笔：0.09 / 0.34，软边 + 多层水渍 + 边缘不规则打毛，笔宽 ×1.35
- 「书写笔 / 毛笔 + 实线」时改用 perfect-freehand 生成带压感轮廓一次填充（`simulatePressure`、首尾 taper），其余组合走印章。
- 线型：不能用 `setLineDash` 与印章混用；改为累计里程 `dashPos` 做门控，实线段盖章、间隙段跳过（虚线 dash = 笔宽×2.2 / gap×1.6，点线 0.25 / 1.9）。
- 单笔绘制时先画到独立预览层，抬笔后按 `globalAlpha = 透明度` 整笔合成到当前图层。笔画内不能因重叠而叠深。
- 光标处显示圆形边界预览（DOM 圆环，直径 = 笔宽 × 缩放），方形笔刷显示为圆角方框。

### 4. 橡皮擦
- 必须**跳过预览层**：按下时直接对当前图层 `globalCompositeOperation = 'destination-out'` 逐点盖章，边走边擦（否则预览层会画出黑线）。
- 专用硬边笔尖（实心圆 / 实心方，无渐变无镂空），间距固定 `max(0.7, 笔宽 × 0.06)`，避免边缘出现扇贝状缺口。
- 光标预览环用虚线边框。

### 5. 图形
- 左键拖拽生成；模型为 `{type, cx, cy, w, h, rot, dirX, dirY, color, lw, fill, dash}`，绘制时 `translate(cx,cy) + rotate(rot)`，路径以中心为原点。
- 选中后显示虚线包围框 + 8 个白色方块手柄 + 顶部旋转圆点（手柄尺寸按 `1/缩放` 自适应，缩放后依然好点）。
- 8 点可改宽高（对角锚点固定，旋转后方向依然正确）；旋转柄可任意旋转，按住 Shift 吸附 15°；空白处拖动可整体平移。
- 光标随手柄方向 + 旋转角变化为 `ew/ns/nwse/nesw-resize`。
- 「填充」勾选时填充实色（直线/箭头不填充）。虚线/点线同样生效。抬笔落地到图层，可撤销。

### 6. 文字
- 点击画布在该位置弹出多行 `textarea` 就地编辑（自由定位、随画布缩放重新布局，编辑时不撑高画布）。
- 设置条：9 种字体（微软雅黑/宋体/黑体/楷体/仿宋/Arial/Georgia/Times New Roman/Courier New）、字号 8–300（默认 32）、左/中/右对齐、加粗 B、斜体 I、下划线 U、删除线 S。
- 样式（字体、字号、对齐、粗斜体、下划线、删除线）改动要**同时作用于正在编辑的文字和已选中的文字**；下划线画在行底 `ly + 字号×1.1`，删除线在 `ly + 字号×0.6`，多行逐行绘制。
- 点击空白处 / Esc 完成落地；不要文字背景填充。

### 7. 钢笔（贝塞尔）
- 单击添加锚点，按住拖动拉出对称手柄（`ix = 2x - ox`）；锚点、手柄线、手柄圆点实时可见。
- 曲线用 `bezierCurveTo` 连接；鼠标悬停时显示到最后锚点的预览段。
- **点回起点（9px 内）闭合路径**，双击同一点 / Enter 完成开放路径，Esc 取消；工具条另给「完成 / 取消」按钮。
- 闭合只连成封闭轮廓，**只描边，不做任何填充**（不提供填充选项）。
- 路径用当前颜色、笔宽、线型、透明度一次性落到当前图层。

### 8. 油漆桶
- 扫描线洪水填充，容差 32（RGB 各通道差值），只填与落点连通的同色区域，遇线条边界自然停下。
- 同色区域直接跳过（幂等）；填充后刷新缩略图并入历史。

### 9. 选择 / 变换 / 裁剪
- 拖框选中「当前图层」的矩形区域：把该区域从图层里真正剪下来（图层对应位置清空），内容作为浮动对象画在叠加层。
- 浮动内容支持：整体拖动、8 点缩放（对角锚点固定）、旋转（Shift 吸附 15°）。
- 专属浮层工具条提供：**裁剪图层**（只保留选区内容，其余区域清空）、**删除**、**完成**。
- Enter 落地（按 DPR 换算保证清晰度），Esc 提交，落地与裁剪都可撤销。

### 10. 图层
- 多图层，每层一个独立 canvas，按顺序叠放；当前图层高亮。
- 列表项显示 48×30 实时缩略图（白底 + 缩小绘制）、图层名、眼睛图标切换显隐。
- 支持 HTML5 拖拽排序（拖动时显示蓝色落点指示线）、↑ 上移、↓ 下移、删除当前图层、新建图层。
- 切换/新建/删除图层前，先把未提交的图形、文字、钢笔、选区落地。
- 新建、删除、排序都要进历史。

### 11. 历史
- 快照式：每次操作前记录所有图层的 `toDataURL`（含当前图层 id、可见性），栈上限 40 步。
- 撤销/重做要能还原图层结构（增删层、换序、显隐）与画面内容；无历史时按钮置灰。

### 12. 缩放与平移
- `.paper` 用 `transform: translate(x,y) scale(z)`，滚轮以光标为锚点缩放（0.1–8）。
- Ctrl+= / Ctrl+- / Ctrl+0（适应窗口）；空格 + 拖动、鼠标中键拖动平移（拖动时手型光标）；初始自动「适应窗口」并居中。
- 缩放条实时显示百分比。

### 13. 主题
- 浅色 / 深色两套 CSS 变量（背景、面板、边框、文字四级灰、主色、阴影、遮罩）；`html[data-theme]` 切换，0.18s 过渡；纸面永远是白色。
- 首屏在 `<head>` 最前面用内联脚本读 `localStorage['draw-theme']`，无记录则跟随 `prefers-color-scheme`，避免刷新闪白。
- 切换按钮图标：浅色模式显示月亮（点击去深色），深色模式显示太阳。

### 14. 自定义光标
- 用 SVG data-URI 自绘光标，白色粗描边打底 + 深色细描边，深浅底色都清晰：图形/选择用十字准星、文字用 I 形、钢笔用笔尖、油漆桶用桶形，热点对准笔尖。
- 画笔/橡皮擦不用系统光标，用 DOM 圆环表示笔宽。

### 15. 导出与清空
- 保存：先把未提交内容落地，再新建离屏 canvas 铺白底、按顺序合成**可见图层**，导出 PNG 或 JPG(0.95)，文件名 `drawing_YYYYMMDDHHmmss.png`。
- 清空：二次确认弹窗（写明会清空所有图层、可撤销），确认后清空全部图层并进入历史。

### 16. 快捷键
`Ctrl+Z` 撤销 · `Ctrl+Y` / `Ctrl+Shift+Z` 重做 · `Ctrl+S` 保存 · `Ctrl+=` / `Ctrl+-` / `Ctrl+0` 缩放 · `B` 画笔 · `E` 橡皮擦 · `R` 图形 · `T` 文字 · `P` 钢笔 · `F` 油漆桶 · `M` 选择 · `D` 主题 · `[` `]` 笔刷大小 ±2 · 空格平移 · `Enter` 完成（钢笔/选区）· `Esc` 取消 · `Delete` 删除选区内容 · 文字工具下 `Ctrl+B/I/U`、`Ctrl+Shift+X` 加粗/斜体/下划线/删除线。在输入框内输入时不触发画布快捷键。

结构约定（改动请沿用以保持一致性）：
- 文档坐标 1600×1000，`paper` 用 `translate + scale` 变换；`zoom.z` 是当前缩放比；屏幕坐标转文档坐标用 `toLogical(e)`。
- 图层：`layers[]`（`{canvas, ctx, name, visible, thumb, id}`）+ `activeLayer()`；所有绘制都落到 `activeLayer().ctx`。
- 三层画布：各图层 canvas（内容）→ `strokeCanvas`（笔画预览）→ `shapeCanvas`（图形/选区/钢笔叠加与手柄）。
- 状态集中在 `state`（tool/color/size/opacity/lineStyle/brush/shapeType/text…）；工具切换统一走 `setTool()`，其中调用 `finalizePending()` 落地未完成内容。
- 每个会改动画面的操作，先 `pushHistory()`；撤销 `undo()` / 重做 `redo()` 基于 `snapshotState()` 的 dataURL 快照。
- 主题色只走 CSS 变量（`--surface` `--border` `--text` `--accent` 等），不要硬编码颜色；纸面保持白色。
- 光标：`toolCursor()` 分派 SVG 光标，画笔/橡皮擦用 `#cursorPreview` 圆环。

改完请自检：抽出内联 `<script>` 用 `node --check` 验证语法；必要时用 headless Chrome 注入测试脚本验证像素/尺寸结果；不要引入新依赖（除已有的 perfect-freehand）。
